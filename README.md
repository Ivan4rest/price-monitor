# Монитор цен

Демо-проект: парсер каталога интернет-магазина, который хранит историю цен, находит изменения между запусками и выгружает отчёт в Excel.

*Price monitor (Python, httpx, BeautifulSoup, SQLite, openpyxl): crawls a shop catalogue, keeps price history, detects changes between runs and exports an Excel report. Optional Telegram alerts.*

## Что умеет

- Обходит каталог по страницам с паузой между запросами и повторами при сбоях сети и ответах 429/5xx.
- Сохраняет каждый проход в SQLite — накапливается история цен.
- Сравнивает проход с предыдущим: новые товары, пропавшие, изменение цены (с процентом) и наличия.
- Выгружает Excel-файл с двумя листами: «Цены» и «Изменения», с фильтрами и закреплённой шапкой.
- Присылает сводку изменений в Telegram, если заданы `TG_BOT_TOKEN` и `TG_CHAT_ID`.

Источник описан в `pricemon/site.py` набором CSS-селекторов — чтобы подключить другой магазин, код сбора менять не нужно.

В демо используется [books.toscrape.com](https://books.toscrape.com) — учебный сайт, созданный для отработки парсинга.

## Запуск

```bash
python -m venv .venv
.venv/Scripts/pip install -r requirements.txt   # Linux/macOS: .venv/bin/pip
.venv/Scripts/python -m pricemon --pages 3 --out prices.xlsx
```

Пример вывода при повторном запуске:

```
Собрано товаров: 60. Отчёт: prices.xlsx
Изменений: 2
• Sharp Objects: 47.82 → 42.5 (-11.1%)
• Soumission: нет в наличии
```

Параметры: `--pages` — число страниц, `--db` — файл базы, `--out` — файл отчёта, `--delay` — пауза между запросами.

Для регулярного запуска добавьте команду в планировщик задач (cron или Планировщик Windows).

## Тесты

```bash
.venv/Scripts/pip install pytest
.venv/Scripts/python -m pytest
```

Разбор проверяется на сохранённой странице настоящего каталога, сеть в тестах не используется.

## Устройство

| Файл | Назначение |
|---|---|
| `pricemon/site.py` | Описание сайта: адрес и селекторы |
| `pricemon/fetch.py` | Загрузка страниц, повторы, обход каталога |
| `pricemon/parse.py` | Разбор карточек товаров и цен |
| `pricemon/storage.py` | История в SQLite, поиск изменений |
| `pricemon/report.py` | Excel-отчёт и текстовая сводка |

## Ограничения демо

- Рассчитан на каталоги с обычной HTML-вёрсткой; для сайтов, которые рисуют товары скриптами или защищаются от сбора, нужен другой способ загрузки.
- Перед сбором данных с чужого сайта проверьте его условия использования и `robots.txt`.
